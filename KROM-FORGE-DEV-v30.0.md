# KROM FORGE DEV v30.0 — Autonomous Product Experimentation & Optimization Engine

v30 adds controlled product experimentation on top of the product-journey layer. It does not invent analytics results. It creates measurable hypotheses, rollout cohorts, telemetry contracts, KPI guardrails, evidence requirements, anomaly rules and an optimization gate.

Core flow:
Prompt/Feature -> Journey -> Hypothesis -> Experiment Plan -> Guardrails -> Cohorts -> Telemetry -> Evidence -> Optimization Gate -> Adopt/Revert

State is stored under `.krom/v30-product-optimization/`.
