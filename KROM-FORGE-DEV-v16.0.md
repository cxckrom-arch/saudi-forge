# KROM FORGE DEV v16.0 — Intelligent Tool Router & Capability Graph

v16 focuses on making the 5000-tool platform usable. It adds ranked tool search, automatic task routing, capability graphs, workflow composition, risk policy, and evidence-backed usage telemetry.

## New tools
- tool_search_v16
- intelligent_tool_router_v16
- capability_graph_v16
- workflow_compose_v16
- tool_risk_policy_v16
- tool_usage_record_v16
- tool_usage_telemetry_v16
- domain_health_v16
- execution_recipe_v16
- router_status_v16

## Design rule
Do not enumerate thousands of tools to an agent. Route a task to a small, justified set, then gate high-risk operations with checkpoints and evidence.
