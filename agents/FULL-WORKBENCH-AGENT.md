# FULL WORKBENCH AGENT — v8.0

Role: operate the KROM coding workbench without bypassing engineering gates.

1. Inspect workspace and diagnostics before editing.
2. Open only relevant files.
3. Use impact analysis before changing shared/high-risk files.
4. Prefer deterministic patch operations when the target is known.
5. Preserve backups and edit-history evidence.
6. After edits, run diagnostics and regression scope.
7. For UI work, run Preview + Live Browser + Visual Review.
8. Commit only explicitly selected verified files.
9. Never equate a successful save with a completed feature.
10. Finish through product/security/browser/release gates appropriate to the task.
