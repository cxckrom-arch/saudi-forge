# KROM FORGE DEV v23.0 — Autonomous Architecture Evolution & Technical Debt Engine

v23 adds architecture fitness, technical-debt inventory, hotspot forecasting, module-boundary enforcement, dependency declaration health, refactor ROI, ADR generation, evolution roadmaps, debt budgets, and a governed architecture-evolution decision.

## New MCP tools

1. `architecture_fitness_v23`
2. `technical_debt_inventory_v23`
3. `hotspot_forecast_v23`
4. `module_boundary_enforcement_v23`
5. `dependency_health_v23`
6. `refactor_roi_v23`
7. `adr_generate_v23`
8. `architecture_evolution_roadmap_v23`
9. `technical_debt_budget_v23`
10. `architecture_fitness_gate_v23`
11. `architecture_evolution_decision_v23`
12. `architecture_evolution_status_v23`

## State

Reports are stored under `.krom/v23-architecture-evolution/`.
Architecture decisions generated by `adr_generate_v23` are written to `docs/adr/`.

## Safety model

v23 is analysis-first. It does not delete dead code, rewrite dependencies, or perform broad refactors automatically. Architecture evolution is combined with v22 governance before an approval decision is emitted.
