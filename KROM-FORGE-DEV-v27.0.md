# KROM FORGE DEV v27.0 — Autonomous Full-Stack Feature Factory

v27 turns a requested feature into a verified vertical slice across UI, domain logic, API, data, permissions, tests and telemetry.

## New tools
- feature_spec_v27
- feature_data_model_v27
- feature_api_contract_v27
- feature_permission_matrix_v27
- feature_ui_contract_v27
- feature_test_matrix_v27
- feature_telemetry_contract_v27
- fullstack_feature_plan_v27
- feature_completeness_v27
- feature_gap_repair_v27
- fullstack_feature_gate_v27
- fullstack_feature_status_v27

Artifacts are written to `.krom/v27-fullstack-feature-factory/`.

## Delivery path
Feature request -> Feature spec -> Data/API/permissions/UI contracts -> Test matrix -> Implementation plan -> Evidence -> Completeness -> Gap repair -> Full-stack feature gate.
